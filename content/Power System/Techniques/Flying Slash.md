%% # Flying Slash %%

%% What does this technique look like when it fires? What is the first image it creates for a reader or viewer? %%

> [!abstract]
> A base [flying slash](https://powerlisting.fandom.com/wiki/Slash_Projection) technique that is derived and evolved into more powerful techniques.

## Mechanics
%% Every technique was defined through meditation — a "conversation" with the user's inner IPS deity. The deity names it. If two people independently define the same technique with zero variation, they get the same name. %%
- **[[IPS Energy]] Cost**: Low (1,000)
- **Actions Required**: Chanting technique name
- **Conditions**: Target can be defined, lowers costs 4x making it very cost efficient

## Effects
%% What does the technique actually do? Be specific about range, duration, and what it physically interacts with. %%
- Can have indefinite range if target is not defined
- If target is defined the slash will attempt to go through them
- Slashes are practically instant
- Slash can be as wide as the user wants
- Cannot cut through steel (if someone uses a defensive [[IPS Technique|technique]] that mimics the durability of steel they would survive)
