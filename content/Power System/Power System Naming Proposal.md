## All names will have kanji/hanzi associated with it
 this is so that can be translated to either Chinese or Japanese purely depending on how the series goes name wise

_currently using Japanese names_

*  [[Imaginary Power System]] - **Yuishiki** (唯識)
* Practitioners - **Gyōja** (行者) or **Yuishikisha** (唯識者)/ **Shikisha** (識者)
* [[IPS Energy]] - **Joriki** (定力)
	* IPS Aura - **Kiai** (気合) or **Shikuhi** (識皮)
* [[IPS Technique]] - **Hō** (法)
	* Mental list of techniques - **Naiteki taizen** (内的大全)
* [[Technique Burn-In]] Process - **Kunjū** (薫習)
* [[Pacts]] - **Kishō** (起請)
	* Eternal damnation - Muken (無間)
